# HVAC OS — موقع التعريف والتوزيع

صفحة هبوط + قناة تحديثات برنامج **HVAC OS** (منصة المهندس الشاملة للتكييف والطاقة).

## النشر (مرة واحدة، مجاني)
1. أنشئ مستودع GitHub عام باسم `hvac-os`
2. من هذا المجلد:
   ```
   git push -u origin main
   ```
3. في GitHub: Settings → Pages → Source: **Deploy from a branch** → `main` / `/ (root)` → Save
4. الموقع يصبح: `https://ezedhamza-lang.github.io/hvac-os/`

## التحديثات
- عند كل إصدار جديد: عدّل `version.json` (رقم الإصدار + رابط التحميل) وارفعه —
  المستخدمون يرون تنبيه «يتوفر إصدار جديد» داخل البرنامج تلقائيًا.
- Releases: ارفع `HVAC_OS_Setup_vX.Y.Z.exe` من صفحة Releases في المستودع —
  رابط التحميل العام: `https://github.com/ezedhamza-lang/hvac-os/releases/latest`

## قبل البيع
- استبدل رابط واتساب `https://wa.me/` برقمك الكامل مع رمز الدولة (مثل `https://wa.me/213555123456`)
- حدّث السعر في قسم «السعر» إن رغبت
